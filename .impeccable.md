# Design Context — mwdeveloper.tech (portfolio hire-me, redesign 2026-07)

## Design Context

### Users
European tech recruiters, hiring managers and founders evaluating a senior
full-stack candidate (remote EU roles); secondarily, freelance prospects.
Context: skimming dozens of candidate links, 30-90 seconds of attention,
mostly desktop, sometimes mobile. Job to be done: verify fast that this
person ships real product (production apps, real numbers), check
location/timezone/work authorization, download CV, reach out.

### Brand Personality
Three words: **builder** (ships end-to-end, first commit to paying customer),
**direct** (numbers over adjectives, no guru tone), **playfully-engineered**
(fun expressed through working interactive details, not decoration).
Emotional goal: "this person ships, and I'd enjoy working with them."
Owner quote: "Transformo problema de negócio em produto usado por cliente
pagante, ponta a ponta. Engenheiro de produto, não dev de uma camada só."

### Aesthetic Direction
Dark, cinematic, typography-led. Existing brand tokens are the base and are
kept: void #06060c bg, electric blue #0066ff primary, cyan #00d4ff (sparing),
DM Sans body, JetBrains Mono for code voice. Evolution decisions (conscious,
documented):
- Display font ADDED for hero/headings: **Bricolage Grotesque** (variable,
  ink-trap personality; "bricolage" = tinkering/building — on-concept for a
  builder). Body stays DM Sans (brand continuity; distinction lives in the
  display layer). Mono stays JetBrains Mono.
- New RARE warm accent `--color-ember` (warm amber, OKLCH) reserved for the
  playful/human moments (terminal cursor, easter eggs, hand-note details) so
  the palette isn't the generic dark+cyan AI look. Blue stays the brand accent;
  cyan demoted to occasional glow.
- Palette expressed in OKLCH; neutrals tinted toward the blue hue.
References: tamalsen.dev (cinematic type), ewan-kerboas.fr (huge type,
open-to-work badge), robbowen.digital (fun, human), brittanychiang.com
(reading discipline, quiet confidence). Anti-references: generic template
portfolios, guru/oversell tone, glassmorphism-everywhere, identical card grids.

### Design Principles
1. Evidence over adjectives — every claim carries a real number or a real
   screenshot (approved numbers only; zero fabrication).
2. The site itself is the skill demo — interactive details must WORK
   (live CET clock vs visitor timezone, terminal, command palette), never
   decorative fluff.
3. Typography does the heavy lifting; motion is few, orchestrated, and
   respects prefers-reduced-motion.
4. Fun is precise — one wink per section, never noise (Robb energy,
   Brittany restraint).
5. Accessibility is non-negotiable — keep a11y 100 (semantic dl/ol patterns,
   focus rings, AA contrast).
