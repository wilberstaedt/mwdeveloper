Privacy Policy — Naylume Money Factory

Last updated: September 2026

Introduction

Naylume Money Factory is a private internal automation system operated by Naylume to manage our own digital products, Pinterest content, and related analytics.

Pinterest integration

The application may connect to Pinterest through the official Pinterest API using OAuth authorization.

The integration may access information necessary to manage the Naylume Pinterest business account, including:

  • Pinterest account information authorized through OAuth
  • Boards
  • Pins
  • Pin and board analytics
  • Engagement and performance metrics necessary to measure content performance

The application does not request or store Pinterest usernames or passwords.

Use of data

Data accessed through the Pinterest API is used only to:

  • create and manage Naylume Pins
  • manage Naylume boards
  • link Pins to Naylume product listings
  • monitor content performance
  • improve Naylume’s own content and marketing decisions

Third parties

We do not sell, rent, or trade Pinterest user data.

The application is not offered to external customers, other Pinterest users, or third-party businesses. It is used solely by the Naylume team for Naylume’s own account.

Data storage and security

OAuth tokens and integration credentials are stored securely and are used only for the Naylume account authorized by us.

We apply reasonable technical measures to protect credentials and integration data from unauthorized access.

Data retention

We retain integration data only for as long as necessary to operate the Naylume Money Factory and analyze Naylume’s own Pinterest content.

Revocation and deletion

Access to the Pinterest integration can be revoked at any time through the Pinterest account settings.
